# Demo sites (static builds)

Server-less demo builds of the redesigned apps, with sample data served by an in-page shim:

- `archiveflow/` — أرشيف المعاملات
- `invoicehub/` — أرشفة الفواتير

Each folder is a plain static site (publish root = the folder). `404.html` is a copy of `index.html` so client-side routes keep working on refresh.
